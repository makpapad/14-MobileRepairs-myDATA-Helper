# 🚀 Οδηγός Ρύθμισης & Αναδιάρθρωσης (Hermes AI Agent)
## Project: MobileRepairs myDATA & VIES Helper

Αυτό το έγγραφο καθοδηγεί τον Hermes AI Agent στην αναδιάρθρωση (refactoring), την εκτέλεση και τη συντήρηση της εφαρμογής Next.js για την υποβολή στοιχείων στο myDATA (ΑΑΔΕ) και τους πίνακες VIES.

---

## 🎯 Στόχος & Βασικές Δυνατότητες

Ο σκοπός της εφαρμογής είναι η αυτόματη επεξεργασία τιμολογίων PDF από προμηθευτές ΕΕ και Εσωτερικού, η εξαγωγή δομημένων δεδομένων μέσω του Gemini API (Multimodal OCR), η ταξινόμησή τους σύμφωνα με την ελληνική φορολογική νομοθεσία (Ν. 5144/2024) και η προετοιμασία τους για υποβολή στο myDATA και στο VIES.

---

## 🏗️ Τεχνολογικό Στάκ (Stack)

- **Framework:** Next.js 15 (App Router)
- **Βάση Δεδομένων / ORM:** PostgreSQL + Prisma ORM
- **OCR & Εξαγωγή:** `@google/genai` (Gemini 2.5 Flash)
- **Styling:** Tailwind CSS v4
- **Γλώσσα:** TypeScript
- **Testing:** Vitest

---

## 🤖 Εργασίες Αναδιάρθρωσης για τον Hermes AI

### Εργασία 1: Αντικατάσταση του PDF-Parse με το Gemini API
- **Αρχείο:** `src/lib/pdf/geminiParser.ts` (Δημιουργία νέου)
- **Ενέργεια:** Υλοποίηση του `@google/genai` με χρήση του μοντέλου `gemini-2.5-flash` και αυστηρό JSON Schema.
- **Εξαγωγή:** Δομημένο JSON που περιλαμβάνει: `supplierVat`, `netAmount`, `vatAmount`, `grossAmount`, `vatRate`, `isReverseCharge` και `hasGoods`.

### Εργασία 2: Ενημέρωση Κανόνων Ταξινόμησης (Rules Engine)
- **Αρχείο:** `src/lib/classification/rules.ts`
- **Ενέργεια:** Βασική αναγνώριση μέσω ΑΦΜ προμηθευτή:
  - `HU12648797` (Marseus Computer Kft) ➔ `14.1` (Ενδοκοινοτική Αγορά Αγαθών, VIES Στήλη 5).
  - `IE3668997OH` (Google Cloud), `IE6388047V` (Google Ads), `DE812871812` (Hetzner) ➔ `14.3` (Ενδοκοινοτική Λήψη Υπηρεσιών, VIES Στήλη 7).
  - `IE9825613N` (Google Commerce / 24% Ελληνικός ΦΠΑ) ➔ `14.3` (Εγχώριες πράξεις λήπτη / OSS), **ΕΞΑΙΡΕΙΤΑΙ ΑΠΟ ΤΟ VIES**.

### Εργασία 3: Προσαρμογή του Handler Ανεβάσματος (Upload Route)
- **Αρχείο:** `app/api/invoices/upload/route.ts`
- **Ενέργεια:** Δρομολόγηση των αρχείων μέσω της `parsePdfWithGemini()` πριν την κλήση της `createInvoiceFromText()`.
